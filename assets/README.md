# Εικαστικά δράσεων

Οι εικόνες προέρχονται από τα ήδη δημιουργημένα εικαστικά των παιχνιδιών. Έγινε μόνο προσαρμογή μεγέθους και συμπίεση για χρήση στη σελίδα.

- `nautilos.webp`: ΝΑΥΤΙΛΟΣ 21, αρχικό `work/poster-assets/background-01.png` από το έργο Ναυτίλου.
- `stigma.webp`: ΤΕΛΕΥΤΑΙΟ ΣΤΙΓΜΑ / ΠΡΩΤΕΥΣ, αρχικό `output/promo/posters-v3/backgrounds/background_01.png` από το έργο Στίγματος.
- `biodive.webp`: BioDive, αρχικό `output/pdf/BioDive_Posters/assets/illustration-01.png`.

Η αντιστοίχιση γίνεται στον κατάλογο `programs` του `schedule-rules.js` με βάση το όνομα και τις εναλλακτικές ονομασίες του παιχνιδιού. Και τα τρία παιχνίδια εμφανίζονται πάντα στο φίλτρο και στα στατιστικά, ακόμη και με μηδενικές δράσεις, με μικρογραφία του αντίστοιχου εικαστικού. Νέα δράση γνωστού παιχνιδιού αποκτά αυτόματα το ίδιο εικαστικό στη λίστα, στις λεπτομέρειες του ημερολογίου και στην επόμενη δράση. Άγνωστο παιχνίδι εμφανίζεται κανονικά χωρίς εικόνα.

Η χρωματική παλέτα βασίζεται στην [επίσημη ιστοσελίδα του Ιδρύματος](https://www.laskaridisfoundation.org/): βαθύ μπλε `#0c1537`, μπλε `#24305a`, χρυσό `#ceaa46`, υπόλευκο `#fffaf1`.

Τα αρχεία εμφάνισης φορτώνονται με αναγνωριστικό έκδοσης στο URL. Σε μελλοντικές αλλαγές εικόνων, CSS ή JavaScript ενημερώνουμε το αντίστοιχο `v` στο `index.html` ή στον κατάλογο `programs`, ώστε οι επισκέπτες να μη βλέπουν αποθηκευμένα παλιά αρχεία. Σε ενημέρωση προγράμματος αλλάζουμε αντίστοιχα το `v` του `data.js`.
